# HDMI Display 宣传文案

## 一句话

**一台 NAS，接几块屏，就是几台独立电脑。**

## 核心卖点

- 每个 HDMI/DP 接口独立输出，不是镜像
- 每块屏可显示不同内容：视频、图片、Windows RDP、VNC 虚拟机、网页、画中画
- 一屏一套键鼠，绑定到对应屏幕
- 飞牛 fnOS 原生 fpk，中文安装/配置/卸载
- 直接 DRM/KMS 输出，不需要桌面环境
- 内置管理面板，随时切换信号源

## 30 秒演示脚本

1. 镜头：一台 NAS，后面插着几根 HDMI/DP 线。
2. 镜头拉远：几块显示器依次亮起。
3. 第一块屏：电影/直播。
4. 第二块屏：Windows 11，键鼠直接操作。
5. 第三块屏：虚拟机控制台/VNC。
6. 第四块屏（如果接口够）：网页、监控或数字标牌。
7. 切回 NAS 管理面板：点一下，换源、开画中画、绑定键鼠。
8. 字幕：**有几个视频输出口，就能带几块屏。**
9. 字幕：**不是镜像，每块屏都是独立内容。**

## B站简介

一台飞牛 NAS，接上几块 HDMI/DP 显示器，每块屏独立显示不同内容：
一块放视频，一块连 Windows RDP，一块看虚拟机 VNC，还能加网页、监控和画中画。
每套键盘鼠标绑定到对应屏幕，管理面板统一切源。

不是镜像，不是远程桌面窗口铺满，而是直接 DRM/KMS 多路输出。
视频、图片、RDP、VNC、网页、画中画都能用；网页源需要 xvfb + chromium，其他源开箱即用。

硬件和 Windows 授权决定实际能带几台，轻办公、家庭实验室、数字标牌场景可以先玩起来。

## 什么值得买 / 飞牛论坛长文开头

**一台 NAS，能不能当几台办公电脑用？**

我现在的做法是：

- 在 NAS 上创建多个 Windows 11 虚拟机；
- 每个虚拟机分配一块 HDMI/DP 输出；
- 每块屏配一套键盘鼠标；
- 用 HDMI Display 把每个虚拟机的桌面直接送到对应显示器；
- 网页后台统一管理，随时切换视频、RDP、VNC、网页和画中画。

这套东西适合：

- 小型轻办公：浏览器、Office、ERP、网页系统；
- 家庭实验室：多台虚拟机、多块屏、多套键鼠；
- 数字标牌/展示：不同屏幕放不同内容；
- 已经有 NAS 和多屏，不想再买几台主机的人。

不适合：

- 视频剪辑、CAD、3D、游戏；
- 对单点故障零容忍的生产办公；
- 没有多视频输出接口的 NAS。

## 功能清单（发布时可直接用）

- 多 GPU / 多卡输出，按连接器独立管理
- 每屏独立信号源：视频/直播、图片、本机画面、RDP、VNC、网页、画中画、仪表盘、测试图
- RDP/VNC 自动识别：含 `@` 走 RDP，主机:端口或本地 socket 走 VNC
- 本机虚拟机自动扫描：`/var/run/vms/*.vnc.sock` 直接选择
- 键鼠按屏幕绑定，支持多套键鼠
- 画中画坐标映射，键盘跟随最后进入的层
- 网页源 Chromium + Xvfb，键鼠 XTEST 注入
- 内置中文管理面板：预览、切源、分辨率、输入绑定
- 飞牛生命周期：安装=打开，停止=启用，升级保持状态
- 最小 FFmpeg/FreeRDP 打包，31 MB 左右

## 发布时主动说明

- 能带几块屏取决于 GPU 输出接口/CRTC/带宽，不是软件固定数量。
- Windows 11 虚拟机需要 TPM/UEFI，正式办公需确认 Windows 授权。
- 网页源需要 `xvfb + chromium`，约 300–450 MB；其他源不需要。
- 单 NAS 是单点，重要办公建议 UPS、快照和备份。
- RDP 账号密码保存在本机配置，面板不要直接暴露公网。
- VNC 目前只支持无认证，建议只走本机 socket 或可信内网。
- 视频会议、USB 摄像头、独立 USB 耳机路由目前不是强项。
