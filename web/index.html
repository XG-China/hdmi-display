使用说明

远程连接只有一个输出方式“远程连接”，后台会根据地址自动判断是 RDP 还是 VNC，不需要手动加前缀。

RDP（Windows 远程桌面）：地址格式为 用户:密码@主机[:端口]。后台看到 @ 就按 RDP 连接，例如 Administrator:密码@10.0.0.5:3389。先在 Windows 上以管理员运行 enable-rdp.ps1（开启 RDP、放行防火墙、把帧率上限提到 60fps），重启一次。默认连接控制台会话（+admin），地址后加 ?normal 改用独立会话。

VNC（虚拟机/无 RDP 设备）：地址格式为 主机:端口、/var/run/vms/xxx.vnc.sock 或 /path/to/socket。后台看到本地 socket 路径或非 RDP 地址就按 VNC 连接，例如 10.0.0.20:5900 或 /var/run/vms/xxx.vnc.sock。

本机虚拟机由系统自动扫描 /var/run/vms/*.vnc.sock。选择“远程连接”后会出现“本机 VNC 虚拟机”下拉框；有一个或多个虚拟机时直接选择即可，也可以手动填写 VNC 地址。VNC 仅支持无密码认证；需要 Windows 音频和更好性能时请用 RDP。
